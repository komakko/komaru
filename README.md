# komaru

Fast reference image viewer for Linux, Windows and macOS.

## Install

### Windows:

Download the installer (`komaru-x86_64-windows-setup.exe`) from the [latest release](https://github.com/komakko/komaru/releases/latest) or use the portable (`komaru-x86_64-windows.exe`).

### Linux (x86_64):

Download the binary (`komaru-x86_64-linux`) and install with `./komaru-x86_64-linux --install` or run as-is.

To uninstall, run `komaru --uninstall`.
