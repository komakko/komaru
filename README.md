# komaru

Fast reference image viewer for Linux, Windows and macOS.

## Install

### Windows:

Download the installer (`komaru-x86_64-windows-setup.exe`) from the [latest release](https://github.com/komakko/komaru/releases/latest) or use the portable (`komaru-x86_64-windows.exe`).

### Linux (x86_64):

Install with:
```sh
curl -fsSL https://github.com/komakko/komaru/releases/latest/download/install.sh | sh
```

Or use the portable binary (`komaru-x86_64-linux`).

To uninstall, use `sh install.sh --uninstall` (download the script first).
